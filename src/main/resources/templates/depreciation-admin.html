Recompute Depreciated Values

Recalculates straight-line current value and depreciation amount for every IT asset, fleet vehicle, and survey asset that has both a cost and a known acquisition year, using COA-aligned useful life (IT: 5 years, Fleet: 7 years, Survey: 10 years, 10% residual value). Rows missing a cost or acquisition year are left unchanged. This is a manual, on-demand action - there is no automatic schedule.
